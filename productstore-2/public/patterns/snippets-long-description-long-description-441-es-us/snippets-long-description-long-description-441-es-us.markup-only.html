Funciona porque…
Los minerales de algunos suplementos se cristalizan durante la digestión, lo cual inhibe la absorción. Además, los minerales tienden a estimular la generación de radicales libres durante la digestión. Esta cascada de radicales libres puede 'consumir' los antioxidantes en su multivitamina (vitaminas A, C y E), haciendo que sean casi inútiles.

Oligo® une los minerales a compuestos orgánicos (Oligofructosa y aminoácidos) de un modo similar a como se encuentran naturalmente en las frutas, las verduras y otros alimentos integrales. Este proceso de fusión mantiene a los minerales más disponibles para que el cuerpo los absorba y también los protege, reduciendo su capacidad de generar grandes cantidades de radicales libres. El resultado es que los nutrientes están más disponibles para ser aprovechados para mantener una buena salud.
