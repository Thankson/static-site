Adding the Melaleuca Store to your Home Screen

Tap the button below to download the app and add an icon to your homescreen.

Add To Home Screen

If the button above does not work, follow these steps:

  • 1. Tap on your web browser's dropdown menu icon.
  • 2. With the menu list, select "Add to Home screen".
  • 3. Select "Add". This will add an icon to your device's home screen.
